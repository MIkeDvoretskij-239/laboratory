КАК ЗАПУСТИТЬ ПРОГРАММУ (Windows)
==================================

1. Если на компьютере ещё не установлен Python — установите с сайта
   https://www.python.org/downloads/
   Во время установки обязательно поставьте галочку
   "Add python.exe to PATH".

2. Дважды кликните на файл start_app.bat в этой папке.

   - При первом запуске откроется чёрное окно и программа сама
     установит всё нужное — это займёт пару минут, подождите.
   - После этого автоматически откроется браузер со страницей входа.

3. Если это первый запуск и своей базы данных ещё нет — программа
   создаст логин по умолчанию:
       Логин:  admin
       Пароль: admin123
   Эти данные также будут показаны в чёрном окне.

4. Пока программа работает — чёрное окно должно оставаться открытым.
   Чтобы закрыть программу — просто закройте это окно.

5. Чтобы запустить снова в следующий раз — просто дважды кликните
   start_app.bat ещё раз (установка по новой не потребуется).

Можно сделать ярлык на рабочий стол: правой кнопкой на start_app.bat —
"Отправить" — "Рабочий стол (создать ярлык)".

Эта копия программы работает только на этом компьютере и со своими
собственными данными — она не связана с другими копиями программы.
